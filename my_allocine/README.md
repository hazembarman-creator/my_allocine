# Welcome to My Allocine
A Ruby project designed to practice writing SQL queries on a real movie database.  
You will explore movies, actors, directors, and reviews using SQL joins, conditions, and filtering.

***

## Task
The main task of **My Allocine** is to write SQL queries inside a Ruby file (`my_allocine.rb`).  
Each query answers a specific question about:

- Movies  
- Actors  
- Directors  
- Reviews  

The challenge is to understand the database schema and use SQL joins and conditions correctly.  
This project helps you build confidence in SQL while integrating it inside Ruby code.  


***

## Description
To solve the project, you download the provided SQLite database and write SQL queries inside the `requests` hash in `my_allocine.rb`.
